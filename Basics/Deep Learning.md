# What is Deep Learning?

Deep Learning is a part of Artificial Intelligence (AI) that teaches computers to learn patterns from data — somewhat inspired by how the human brain learns.

It is mainly built using something called **Neural Networks**.


### Simple Real-Life Example

Imagine you want a computer to recognize cats in photos.

Instead of writing rules like:

- cats have whiskers
- cats have ears
- cats have tails

Deep Learning lets the computer learn these patterns by showing it **thousands of cat images**.

After seeing enough examples, it starts recognizing cats on its own.

That learning process is Deep Learning.

##### Why is it Called “Deep”?

Because the neural network has many **layers**.

A simple neural network:

```
Input → Hidden Layer → Output
```

A deep neural network:

```
Input → Hidden Layer → Hidden Layer → Hidden Layer → Output
```
